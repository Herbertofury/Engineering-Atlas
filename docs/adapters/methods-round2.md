## Evidence states and operation boundaries

An observed DOM selector or embedded JSON field is evidence for the exact captured sample. An executed normalizer is a stronger sample extraction result. Deterministic replay proves the same snapshots normalize identically; it does not prove that two source representations contain the same complete body. Documentation describes an available contract; it does not prove a live site enables it. Semantic page observations can support an implementation plan without establishing CSS selectors. A blocked, wrong-page, shell, generic About page or discovery-only listing leaves the requested fields unknown.

Each catalog entry now has `operationEvidence` for its route, identity/avatar, body/media, history, file/entitlement and follow state. `extractionMethodRefs` points to specific recipes where available; an empty array means no round-two recipe is established. Earlier scoped acceptance remains in its original receipts. Every method retains its own limits and `fullSupportAccepted: false`.

Local creator watches are a proposed app capability. Native follow, import, project watch, friendship, favorites and paid membership are distinct operations. This pass did not execute native follow mutations/imports. A loaded image, decoded image, static GIF placeholder, animated GIF, video playback, advertised file hash and locally verified artifact hash also remain separate states.

### Identity and access consequences

The original XMA creator explicitly moved the archive to Heliosphere; retain the announcement and exact destination links instead of pretending the XMA page contains all relocated releases. Its creator avatar is independently verified. Larian demonstrates a different case: the complete visible post can be public while the actual creator-profile URL returns a permission wall. GitHub’s public REST objects preserve release publisher and asset uploader separately. RimWorld Multiplayer’s automated publisher is not its named project creator, and its continuous tag is not automatically a stable-version recommendation. Public download URLs and reported digests are metadata until actual archive bytes and integrity checks exist.

Race Sim Studio identifies an original studio and delegates commerce to Sellfy; counting it as another generic Sellfy platform would inflate coverage. Jotunn is an original Valheim reference project in the existing GitHub family. The old valheim.plus URL redirected to unrelated parking content, so this pass rejects it as a current host without assigning the redirect destination any trust.

## Rejected shortcuts and next gates

Reject whole-page text scraping: it mixes replies, signatures, rank graphics, social badges and recommendations with the post. Reject first JSON-LD descriptions as complete bodies: Ketaros truncates them. Reject a convenient feed as automatically equivalent to DOM/REST: RRE36 and Cryss retain failed parity checks. Reject guessed API/schema fields from CMS appearance, first-member-as-author joins, label-only signed-in state, and native follow from aggregate counts. These shortcuts may simplify extraction but lose required attribution, ordered content or access boundaries.

The next acceptance step is a permitted, reproducible fixture comparison for each required operation. Preserve complete selected rich bodies internally; compare body/media order and identities; test terminal histories and failures; verify only authorized artifacts; independently decode/render/play media; then evaluate account and entitlement flows. A useful sample extractor remains a research result until those operations pass against the intended target.
