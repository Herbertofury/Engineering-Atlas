### Protocol and attribution upgrades

- **Ficsit GraphQL preferred contract:** Official API page publishes https://api.ficsit.app/v2/query with playground/v2; REST/v1 and Swagger separately. REST intentionally incomplete. No query/schema execution or endpoint shape beyond documented URLs accepted. (RDXG31011).
- **Invision thread/file/profile namespaces:** Keep fileID,topicID,commentID and profileID separate. Extract body before replies; author-card/avatar role must be scoped. Followed item and followed person,review pagination and creator-history pagination differ. Sign-in file gates retained. (RDXG31016, RDXG31017, RDXG31019, RDXG31020, RDXG31033, RDXG31034).
- **Restoration provenance and binary identity:** Restored collections may repackage/update originals. Preserve original author,curation uploader,last editor and source timestamps; a cross-linked host is no proof of byte identity. Validate actual files independently. (RDXG31035, RDXG31036, RDXG31037).
- **moddb:** 7Days game directory exposes maintained and explicitly obsolete projects. Original developer The Fun Pimps game credit is not every mod creator. Preserve release/update dates and stale/obsolete labels instead of recommending every listing. (RDXG31042).
- **github:** Outer Wilds display team label links individual Hawkbat account; a byline label and resolved profile type require distinct records. Repository release,individual owner and team contributors must not collapse. (RDXG31027, RDXG31028).

### Remaining gates

- Permitted raw/client fixtures for Flightsim,SRB2,Doomworld,SonicRetro,RainDB and Ficsit without access bypass.
- Five pairs need scoped avatar role/decode,complete body/media,provider playback and per-releasefilemanifest receipts.
- Ficsit allowed GraphQL schema and public GET/readquery fixture; no invented request fields.
- 7Days tab body/gallery/download history and actual advertised RSS hrefs; nativefollow auth/import remains untested.
- Invision source-specific body/profile/pagination fixtures and authorized entitlement only; no hidden visitors/social graph inference.
- Deduplicate restored/repacked SC4 collections by source identity and actual file hashes while preserving curator/original creator roles.

Flightsim actual addon/profile attempts are independent incomplete samples,not a joinedpair.7D2D.net is excluded as hosting. Doomworld,SRB2,Sonic403 and other request failures are retained. No retry was made of the tool-policy-blocked Bdub Discord destination. Public member personal fields unrelated to creator extraction are omitted.
