# X adapter research

[Adapter laboratory](README.md) · Reviewed October 26, 2026

## Current route

Current documentation describes v2 endpoints with pay-per-use pricing. Do not silently create paid integration or assume browser sign-in gives API access.

## Reuse before replacement

Evaluate official SDK/API and supported embeds first; compare maintained media extractors only within permitted access. Preserve IDs as strings.

## Acceptance workload

Post identity; image order; video variants; quoted-post ownership; pagination; deletion/protection changes; rate and spending limits.

## Evidence status

Documentation reviewed; no account grant, paid request or accepted live adapter. No recommendation transfers to a project until it beats that project's actual baseline without sacrificing requirements.
