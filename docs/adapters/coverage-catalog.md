## Reading the evidence

Open each game guide for concrete item/profile pairs, creator and uploader roles, body and media observations, file boundaries and failures. New observations append to existing metadata. Public text retrieval, image URL discovery, displayed images, archive bytes, playback, complete creator history and authenticated entitlement are separate operations.

The source register accepts only `primary_documented`; for incomplete or failed primary-origin locators, `sourceRole: retrieval_attempt`, `primaryContentObserved: false`, the exact `retrievalStatus` and original evidence value explicitly prevent a success claim. The machine manifest retains failures, shells, search leads and unsupported scopes. Source-register presence alone establishes neither page availability nor adapter support.
